Каждая задача: spec → согласование → реализация → локальная проверка → скриншоты → прод. Критерий готовности любой страницы: открывается, в общем стиле, работает на мобильном, не ломает главную, есть мета-теги, у пользователя ясный следующий шаг.

## T0. Согласование базы знаний (эта поставка)

Валерий утверждает: стек (D15), ответы на вопросы из 09. Блокирует T1.

## T1. Каркас

Astro-проект, токены из 05, layouts (Base/Page/Article), шапка/футер/меню, 404, robots.txt, sitemap-интеграция, CNAME, GitHub Actions деплой в отдельную preview-ветку (прод не трогаем). Приемка: пустой сайт собирается, 404 в стиле, PageSpeed 95+.

## T2. Перенос главной

Главная в Astro пиксель-в-пиксель + фиксы: favicon, og:image, canonical, H1, актуализация цифры «10+ лет практики», метро/телефон по ответам из 09. Приемка: скриншот-сравнение до/после, мобильный вид идентичен. Переключение прода - отдельным явным шагом.

## T3. /credentials/

Два трека (психология / бизнес), карточки-превью из 16 сканов + диплом, оптимизация изображений. Текст - из черновика «Об образовании», сверенный с факт-листом. Приемка: страница легкая (превью сжаты), оригиналы открываются, вес страницы < 1 МБ до кликов.

## T4. /about/ и /business/

/about/: текст собирает ИИ из раздела 6.6 мастер-документа + профилей соцсетей, Валерий правит. Структура: путь (бизнес → кризис → терапия → практика), фото из Varios, блок «живой человек», CTA.

/business/ (Р8, отдельная страница): трек 2 мастер-документа + блок 6.4 «что этот опыт дает клиентам»; тон сверить с Facebook-переработкой 2026. EN-версия страницы - в Ф2.

## T5. /therapy/

Как проходит работа, первая встреча, формат/цена, конфиденциальность, границы + FAQ (реальные вопросы из требований 7.2) + ссылка на PDF правил. Источники: правила работы, B17-профиль, мастердок языка. PDF генерируется из канонического файла правил.

## T6. /blog/ + шаблон статьи + миграция

Шаблон статьи (типографика из 05 + editorial-акценты из 11, подпись, CTA, метаданные), список с блоком «Избранное», миграция шорт-листа (D12), 2-3 ссылки на избранное с главной (D11).

Спецификация шорт-листа (что нужно от Валерия): 12-15 материалов.
- 6-7 из Telegram - тексты, продающие как терапевта (кандидаты из закрепа: «маленькое пальто», «морячок из трюма», «нет сил быть героем», «плюшевый мишутка», «терапия как процесс риска», «океан между мной и прошлым»)
- 4-5 с B17 - профессиональные: кейсы, разборы, «терапия без ботвы» (работают на доверие проверяющих квалификацию)
- 2-3 из Дзена - Камино/дорога (человеческое измерение, связка с /about/)
Формат передачи: ссылка на оригинал + текст (файлом или ссылкой), дата публикации. Категории/теги/описания проставлю сам, Валерий утвердит.

## T7. Лендинг группы

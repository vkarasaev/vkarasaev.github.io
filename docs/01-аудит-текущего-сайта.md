## Дизайн (канон, сохраняем)

Концепция «Premium Dark» (док «Дизайн лендинга», март 2025). Полные токены - в `05-визуальные-правила.md`. Кратко: почти черный фон #0E0E10, золото #C9A96E, serif Cormorant Garamond для заголовков, sans Jost для текста, радиус 12px, узкая колонка.

## Сильные стороны (не потерять)

- Скорость: один запрос + шрифты, нет фреймворков, нет трекеров.
- Мобильность: колонка max-width 480px, все идеально на телефоне.
- Конверсионная плотность: CTA в начале и в конце, бесплатная встреча с préfill-сообщением.
- Целостный премиальный стиль, узнаваемый.
- Простота владения: править может человек без разработки.

## Ограничения и долги (что решает v2)

| Проблема | Следствие |
|---|---|
| max-width 480px на любом экране | На десктопе узкая колонка; для контентных страниц (статьи, credentials) нужна более широкая сетка |
| Все в одном файле | Стили и контент не переиспользуются; каждая новая страница = копипаста |
| Сертификаты - ссылка на B17 | Доказательная база на чужой площадке (проблема №2 из требований) |
| Нет favicon | Мелочь, но заметная |
| Нет og:image | Ссылка в мессенджерах без картинки |
| Нет sitemap.xml, robots.txt, canonical | SEO-база отсутствует |
| Нет EN-входа | Проблема №1 из требований |
| Аватар в base64 | Для одного файла ок; в v2 - обычные оптимизированные изображения |
| Заголовки: нет явного H1 | H-структуру привести в порядок при переносе |

## Вердикт: что сохранить, что переписать, что не трогать

**Сохранить как есть (смысл и стиль):** вся структура главной, тексты hero/о себе/подход, CTA-логика, цветовая система, шрифты, компоненты (кнопки, карточки, статистика, сепараторы).

**Переписать технически:** вынести CSS в общий файл/токены, собрать переиспользуемые шаблоны (header/footer/meta), заменить base64-аватар на файл, добавить favicon, OG, canonical, sitemap, robots.

**Рискованно трогать:** CNAME (удаление уронит домен); прод-ветку без проверки (инвариант: главная всегда рабочая). Любое изменение главной - только через ветку и локальный/preview-просмотр.

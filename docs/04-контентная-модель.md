# Контентная модель

Сущности и их поля. Все контентные файлы - Markdown/MDX с YAML frontmatter, ключи типизированы (схемы коллекций Astro проверяют при сборке). Имена файлов - латиница-slug для страниц/статей, NFC для любых кириллических имен в репо.

## Страница (page)

```yaml
title: ""            # H1 и <title>
description: ""      # meta description, 140-160 знаков
lang: ru             # ru | en
hidden: false        # true = вне меню и sitemap.xml
og_image: ""         # путь; если пусто - дефолтная OG
canonical: ""        # только если отличается от URL
translation: ""      # URL парной страницы на другом языке, если есть
```

## Статья (blog)

```yaml
title: ""
description: ""      # SEO + анонс в списке
date: 2026-01-01
lang: ru
slug: ""             # фиксируется навсегда
categories: []       # 1 категория из фикс-списка
tags: []             # до 4, из словаря тегов канала (#выгорание, #мужское...)
source_channel: ""   # telegram | b17 | dzen | vc | linkedin | original
source_url: ""       # оригинальная ссылка
cover: ""            # обложка, опционально
featured: false      # true = блок «Избранные тексты»
draft: false
```

Подпись под статьей - автоматическая: «Валерий Карасаев» со ссылкой на главную + CTA-блок.

## PDF-документ

Папка `public/docs/`, стабильные имена без пробелов: `pravila-raboty.pdf`, `informed-consent.pdf`, `corporate-profile-en.pdf`. Ссылка на PDF никогда не меняется; новая версия перезаписывает файл.

## Изображение

- `public/images/photo/` - фото Валерия (из Top/Varios, отобранные, переименованные осмысленно: `hero-yacht.jpg`, `about-camino-01.jpg`)
- `public/images/covers/` - обложки статей
- `public/certificates/` - оригиналы сканов (имена как переданы, но NFC/без пробелов)
- Превью и адаптивные размеры генерирует сборка; в контент вставляются оригиналы.

## Настройки сайта (единый источник)

# Картинки и блог: как править самому, не сжигая токены

Правило номер ноль: **замена картинки - это перезапись файла с тем же именем**.
Никакого кода трогать не нужно, ноль токенов. Загрузил файл поверх старого - через
2-3 минуты после сборки картинка на сайте новая.

---

## 1. Где лежат картинки

Все картинки сайта - в двух папках внутри `public/`:

| Папка | Что там |
|---|---|
| `public/images/photo/` | Все фото: портреты, hero страниц, обложки статей, аватары |
| `public/images/arch/` | 12 архитектурных кадров (Москва, Берлин, Гданьск) - фонд для обложек |

В коде на них ссылаются как `/images/photo/имя.jpg` (без `public`).

## 2. Размеры и кадрирование

| Тип | Размер | Пропорция |
|---|---|---|
| Обложка статьи (`cover-*.jpg`) | 1200x800 | 3:2, горизонтальная |
| Hero страницы (`*-hero.jpg`) | ~1400px по длинной стороне | вертикальная или 4:3 |
| Аватар / кружок | 600x600 | квадрат |
| Плашка «где я пишу» | подойдет любой квадрат/горизонталь - обрежется автоматически |

Кадрировать можно чем угодно (Preview на Mac, Фото на телефоне). Сохранять в JPG,
качество 80-85. Главное - выдержать пропорцию: обложки статей на сайте всегда
обрезаются в 3:2, так что вертикальное фото потеряет верх и низ.

## 3. Как заменить картинку (через GitHub, без кода)

1. GitHub → репозиторий → папка `public/images/photo/`.
2. Найди файл, который хочешь заменить (карта - в разделе 4), запомни ТОЧНОЕ имя.
3. Переименуй свой новый файл на компьютере в это же имя (например `cover-palto.jpg`).
4. В GitHub: **Add file → Upload files** → перетащи файл → Commit. GitHub заменит старый.
5. Подожди 2-3 минуты (Actions), обнови страницу с Ctrl+Shift+R.

## 5. Блог: как править статьи

Каждая статья - один файл в `src/content/blog/ru/` (английские - в `en/`).
Имя файла = адрес: `vygoranie-v-malenkom-palto.md` → `/blog/vygoranie-v-malenkom-palto/`.

Вверху каждого файла - блок настроек (frontmatter):

```yaml
---
title: "Про выгорание в маленьком пальто"    # заголовок
description: "1-2 предложения для карточки и поисковика"
date: 2026-04-17                              # дата (влияет на порядок)
categories: ["выгорание"]
tags: ["выгорание", "живое"]                  # темы, до 3, из словаря ниже
source_channel: telegram                      # telegram | b17 | dzen | original
cover: "/images/photo/cover-palto.jpg"        # обложка (см. разделы 3-4)
featured: true                                # true = блок «Избранное» на /blog/
draft: true                                   # true = статья НЕ публикуется
placeholder: true                             # пометка «болванка» (плашка в статье)
---
Дальше обычный текст. Разделитель между смысловыми блоками: строка из трех звездочек ***
```

**Заменить обложку статьи:** либо перезаписать файл картинки (раздел 3),
либо поменять путь в `cover:`.

**Убрать/добавить статью в избранное:** поменять `featured: true/false`. В избранном
показываются 3 самые свежие с этим флагом.

**Скрыть статью, не удаляя:** `draft: true`.

**Словарь тегов** (9 штук, новые без нужды не плодить): выбор, выгорание, дорога,
живое, кризисы, нарциссизм, руководители, стыд, терапия.

**Добавить новую статью:** создать файл `имя-латиницей.md` в `src/content/blog/ru/`
с frontmatter по образцу выше. Проще всего - скопировать существующую статью
и заменить содержимое.

## 6. Где лежат тексты страниц (для правки в VS Code)

| Страница | Файл с текстом |
|---|---|
| Обо мне | `src/pages/about/index.astro` |
| Терапия | `src/pages/therapy/index.astro` |
| Группа | `src/pages/groups/vernutsya-v-kontakt.astro` |
| Премиум | `src/pages/premium/index.astro` |
| Главная | `src/pages/index.astro` |
| Новая главная | `src/pages/home/index.astro` |

Текст - это все, что между тегами разметки. Правишь слова, не трогая теги
`<p>`, `<div>` и атрибуты, сохраняешь - и заливаешь файл в GitHub тем же способом
(перезапись файла). Полная карта всех страниц - в `docs/how-to/edit-single-page.md`.

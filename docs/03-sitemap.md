## Скрытые посадочные (по мере необходимости, Ф2+)

- `/lp/linkedin/`, `/lp/expats/`, `/lp/corporate/` и под конкретные рассылки/рекомендации - создаются по запросу, вне меню и sitemap.xml.

## Правила языкового переключения

- Есть версия страницы на другом языке - ссылка на нее в шапке.
- Нет - переключатель ведет на главную соответствующего языка. Никогда на 404.
- hreflang + canonical на всех парных страницах.

## Стабильность URL

URL из этой таблицы фиксируются при запуске MVP и далее не меняются. Любая реструктуризация - только с HTML-редиректом со старого адреса.

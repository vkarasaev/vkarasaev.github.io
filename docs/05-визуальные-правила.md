# Визуальные правила

Канон: концепция «Premium Dark» (док «Дизайн лендинга», март 2025) + фактический CSS текущего index.html. Новые страницы - естественное продолжение, не новая тема.

## Токены (CSS custom properties, уже в проде)

```css
:root {
  --bg: #0e0e10;        /* фон страницы */
  --bg2: #151518;       /* альтернативный фон */
  --surface: #1c1c20;   /* фон блоков/карточек */
  --border: #2a2a30;    /* рамки */
  --gold: #c9a96e;      /* акцент */
  --gold2: #e8c98a;     /* акцент hover */
  --text: #e8e4dc;      /* основной текст */
  --muted: #8a8680;     /* приглушенный */
  --radius: 12px;
}
```
Дополнительные из прода: текст hero-bio #D4D0C8, подписи статистики #A8A49C, темный текст блоков #B8B4AC, hover-фон карточек #232328, золото с прозрачностью rgba(201,169,110,0.05).

## Типографика

- Заголовки: Cormorant Garamond, 300/400/600, uppercase + letter-spacing для имен/названий, обычный регистр для контентных H2.
- Текст: Jost, 300 базовый, 400 для акцентов, 500 для кнопок.
- Фирменные приемы: tagline капсом 12px/2px letter-spacing золотом; курсивный serif для лид-абзацев; золотой divider 48×1px.
- Контентная типографика (новое, для статей и длинных страниц): базовый размер 17-18px, line-height 1.7-1.85, абзацы без отступа первой строки, интервал между абзацами.

## Сетка и ширины (главное новое решение)

- Главная `/`: остается колонкой 480px - это ее жанр (линк-хаб), не трогаем.
- Контентные страницы (therapy, about, blog, principles): колонка текста **max-width 720px**, паддинги 20px по бокам, те же фоны и токены.
- Широкие страницы (credentials-сетка сертификатов, список блога): контейнер до 960px, внутри карточная сетка 2-3 колонки на десктопе, 1 на мобильном.
- Mobile-first всегда: сначала одна колонка, медиазапросы вверх.

## Компоненты (переносятся из прода как есть)

- **Кнопки:** btn-primary (золотая, темный текст), btn-outline (контур), btn-ghost (surface). Радиус 12px, uppercase 13px/1.5px, transition 0.3s.
- **Карточка** (stat-card, подход Г/П/К): surface + border + radius, паддинг 16-24px.
- **Статистика 2×2:** serif-цифра 32px золотом + uppercase-подпись 11px.
- **Сепаратор:** линия-точка-линия (sep-line/sep-dot).
- **Анимация:** fadeUp 0.7s с каскадной задержкой; только на появление, без постоянного движения.

## Новые компоненты (в каноне)

- **Шапка страниц (не главной):** тонкая, имя серифом слева, меню Jost uppercase 12px справа, переключатель EN. На мобильном - бургер или горизонтальный скролл меню (решить в верстке, критерий - простота).
- **FAQ-аккордеон:** surface-карточки, вопрос серифом, `<details>` без JS.
- **Сертификат-карточка:** превью с золотой рамкой 1px при hover, клик - оригинал.
- **CTA-блок конца страницы:** переиспользование блока «бесплатная встреча» с главной.
- **Хлебная крошка/возврат:** «← На главную» приглушенным, где уместно.

## Изображения

- Фото: теплые живые кадры (дорога, вода, горы) в стилистике «не сток, не глянец» - принцип из блюпринта «Топ-топ».
- Формат: WebP/AVIF с fallback, ленивая загрузка ниже первого экрана.
- Сертификаты: превью ~800px по длинной стороне, сжатие; оригинал по клику.
- OG-дефолт: темный фон, имя + tagline золотом; отдельные OG для RU и EN.

## Чего не делать

- Никаких светлых тем, готовых шаблонов, посторонних шрифтов и цветов.
- Никаких каруселей, попапов, чат-виджетов.
- Не перегружать золотом: акцент, не заливка.
- JS - только там, где без него нельзя (цель: ноль на большинстве страниц).

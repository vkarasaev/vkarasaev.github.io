# Архитектура и стек

Статус: предложение (решение D15), требует утверждения Валерием до старта разработки.

## Требования, которым должен отвечать стек

Из инвариантов: GitHub Pages, контент в Markdown/MDX, разделение код/контент/настройки, без CMS и бэкенда, скорость как у текущего сайта, мультиязычность RU + /en/, скрытые страницы, редиректы, sitemap/robots/OG из коробки или почти, управляемость через Claude Code.

## Предложение: Astro

Статический генератор Astro (вывод - чистый HTML/CSS, ноль JS по умолчанию).

Почему именно он:
1. **Content Collections:** статьи, сертификаты, группы, отзывы - типизированные коллекции Markdown/MDX с проверкой frontmatter по схеме. Ровно контентная модель из раздела 9 требований.
2. **i18n-маршрутизация:** `/` и `/en/` как два независимых дерева, частичный перевод - норма, hreflang и переключатель на уровне страницы решаются штатно.
3. **Ноль JS по умолчанию:** страницы собираются в статический HTML, PageSpeed сравним с текущим одностраничником.
4. **GitHub Pages через Actions:** официальный workflow, push в main = деплой, ветки = preview локально. Откат = revert коммита.
5. **Интеграции:** @astrojs/sitemap, генерация OG, оптимизация изображений (astro:assets) - сжатые превью сертификатов делаются автоматически из оригиналов.
6. **Скрытые страницы:** страница без ссылок из меню + исключение из sitemap. Штатно.
7. **Редиректы:** статические meta-refresh/канонические страницы или файл `_redirects`-аналог через генерацию; для GitHub Pages - HTML-редиректы, генерируемые из одного конфига.

Альтернативы, рассмотренные и отклоненные:
- **Чистый HTML (как сейчас):** не масштабируется на блог и двуязычие, каждая статья - ручная копипаста шаблона.
- **Eleventy:** легкий и хороший, но слабее в типизации контента и i18n-эргономике; MDX хуже.
- **Next/Nuxt:** избыточны, тянут JS-рантайм, конфликтуют с требованием легкости.

## Принципы

- Контент никогда не хардкодится в компонентах: тексты страниц - в Markdown/данных, цены и контакты - в одном файле настроек (`src/data/site.ts`): телефон, почта, Telegram, цена сессии, курс 85 ₽/€. Обновление цены = правка одного файла.
- URL фиксируются один раз и не ломаются (раздел 10 п.3 требований). Смена структуры = обязательный редирект.
- Главная переносится в Astro пиксель-в-пиксель, до подтверждения идентичности старый index.html остается в проде.

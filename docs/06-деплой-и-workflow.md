# Деплой и git-workflow

## Текущее состояние

- Репозиторий `vkarasaev/vkarasaev.github.io`, GitHub Pages отдает файлы из main напрямую.
- CNAME = karasaev.com. Не удалять и перенести в `public/` при переходе на сборку.
- DNS: Namecheap, HTTPS автоматический.

## Целевая схема (с Astro)

- Ветка `main` = прод. Push в main запускает GitHub Actions (официальный astro build → deploy pages).
- Рабочие ветки: `feat/<задача>` под каждую задачу из роадмапа.
- Проверка до мержа: `npm run build && npm run preview` локально (или в Claude Code), просмотр скриншотами, чек-лист приемки из 08.
- Откат: `git revert` мерж-коммита, push - прод возвращается за минуты.

## Правила безопасности прода (инвариант)

1. В main не коммитим напрямую ничего, что касается главной.
2. Переход со «старого» index.html на собранную главную - отдельная задача с явным сравнением до/после; до нее старый файл живет в проде нетронутым.
3. CNAME, robots.txt, редиректные файлы - изменения только осознанные, с пометкой в описании PR/коммита.
4. Битые ссылки проверяются перед мержем (линк-чекер в сборке).

## Админские сценарии (повторяемые инструкции для Claude Code)

Каждый сценарий - отдельный файл в `docs/how-to/` репозитория, чтобы задача формулировалась одной строкой:

- **Добавить статью:** создать `src/content/blog/ru/<slug>.md` с frontmatter из 04, положить обложку в `public/images/covers/`, проверить сборку, добавить в featured при необходимости.
- **Добавить сертификат:** скан в `public/certificates/`, md-запись в коллекцию credentials, превью сгенерируется само.
- **Обновить цену:** править только `src/data/site.ts`; евро пересчитывается по курсу 85 с логичным округлением.
- **Добавить отзыв:** md-файл в testimonials с привязкой к продукту.
- **Новая группа:** md в groups + страница `/groups/<slug>/`; хаб не требуется.
- **Скрытая посадочная:** страница с `hidden: true`, проверка, что ее нет в sitemap.xml и меню.

## Аналитика (D8)

Cookie-less: Plausible / Umami / GoatCounter - выбрать один на этапе Ф2 (критерии: цена, простота, EU-хостинг). Подключение - один скрипт в Base-layout, без cookie banner.

# karasaev.com

Сайт психолога Валерия Карасаева на Astro. Ветка `main` = опубликованный сайт; при слиянии в неё GitHub Actions собирает и публикует сайт на GitHub Pages.

- Правила работы в репозитории: `AGENTS.md`.
- Документация проекта (карта сайта, архитектура, дизайн-система, бэклог, релизы, тексты): на Google Диске Валерия, папка «(A2-10) Сайт», файл «00 Навигация».
- Цифры и контакты задаются только в `src/data/site.ts`.
- Локально: `npm install`, затем `npm run dev`; сборка `npm run build`, просмотр сборки `npm run preview`.
